# csv-samples

Sample CSV datasets for data analysis practice.

## sales-data.csv (100 records)
```
ID, Customer, Product, Category, Quantity, Price, Date, Status, Country
```

## library-books.csv (15 records)
```
BookID, Title, Author, Genre, Year, Copies, Available, Rating
```

## restaurant-orders.csv (40 records)
```
OrderID, CustomerName, DishName, Category, Quantity, Price, OrderTime, TableNumber, PaymentMethod
```

## student-records.csv (30 records - contains missing values)
```
StudentID, Name, Age, Major, GPA, Year, Email, PhoneNumber, City
```
